Bài tập thực hành (Exercises)
Exercise 01
Small Image Classification (Softmax, MLP & CNN)
Phân loại trên tập dữ liệu ảnh kích thước nhỏ (MNIST / Fashion-MNIST / CIFAR-10) bằng Softmax Classifier, Multi-Layer Perceptron (MLP) và Convolutional Neural Network (CNN). So sánh accuracy, model capacity, và phân tích phân phối dự đoán lỗi (error analysis).

Exercise 02
Multi-Head Self-Attention (MSA) from Scratch
Tự hiện thực lại Multi-Head Self-Attention (MSA) từ đầu bằng PyTorch. Thử nghiệm các cơ chế tokenization (patch extraction, pixel/row, CNN-stem, CLS + patches, ...) và đánh giá hiệu quả phân loại trên tập dữ liệu ảnh nhỏ.

Exercise 03
Sequence Models (LSTM / GRU)
Hiện thực và so sánh các mô hình xử lý chuỗi Recurrent Neural Networks (LSTM và GRU) với baseline Feed-Forward / 1D-CNN trên các bài toán chuỗi thời gian hoặc phân loại tuần tự.

Generative Models (VAE, GAN & Diffusion)

Assignment 01
CNN vs. Transformer on Large Dataset
Nghiên cứu so sánh toàn diện giữa kiến trúc Convolutional Neural Network (CNN) và Vision Transformer (ViT) trên tập dữ liệu ảnh lớn. Đánh giá đa chiều dưới các chế độ huấn luyện: From-scratch vs Pretrained, cùng các kỹ thuật fine-tuning (Frozen backbone, Partial freeze, Full fine-tuning).
